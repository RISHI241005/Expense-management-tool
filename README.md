# Expense-management-tool
## Features
- Add, update, delete expenses
- RESTful APIs using Spring Boot
- MySQL database integration
- DTO-based architecture
- Global exception handling

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## API Endpoints
- POST /api/expenses
- GET /api/expenses
- GET /api/expenses/{id}
- PUT /api/expenses/{id}
- DELETE /api/expenses/{id}

A simple yet powerful tool to track, manage, and analyze your daily expenses. This project helps users stay on top of their finances by offering clear insights into spending patterns and budget allocation.
